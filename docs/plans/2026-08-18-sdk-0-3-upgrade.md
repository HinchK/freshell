## 3. Architecture

Main's `server/sdk-bridge.ts` is already 0.3-safe (VAL-1 verified type-compat): `createClaudeSdkCleanEnv` strips only `CLAUDECODE`/`ANTHROPIC_API_KEY`; `createClaudeSdkOptions` sets `settingSources: ['user','project','local']`; message routing is `private handleSdkMessage(sessionId, msg)` with switch arms for `system` / `assistant` / `result` / `stream_event` and a debug-log-and-ignore default arm; resume uses top-level `resume` with legacy `sessionId` fallback. Both claude providers (freshclaude, kilroy) share one options surface via `server/fresh-agent/adapters/claude/adapter.ts` → `SdkBridge.createSession` → `createClaudeSdkOptions`; kilroy additionally shares the model-capability registry probe. `server/fresh-agent/model-capability-registry.ts` probes SDK `supportedModels()` through a 10s-abort harness with alias-aware `normalizeFreshAgentModelCapabilityCatalog` (`canon`/`aliases`), `readModelId` (raw `value`→normalized `id`), and typed errors on garbage — which `server/fresh-agent/model-capabilities-router.ts` (`getCapabilities`/`createFailure` chain, `GET /api/fresh-agent/model-capabilities/:sessionType`) converts to 200-fresh / typed-503; responses are `{ok:true,status:'fresh'|'cached',models:[…]}` / `ok:false` (validated shapes, LB-9). Normalized client capability entries are STRICT-schema objects `{id, displayName, provider, supportsEffort, supportedEffortLevels, supportsAdaptiveThinking}` (`FreshAgentModelCapabilitySchema`), NOT `{value, description}` (LB-8). Client: `src/lib/fresh-agent-model-capabilities.ts` fetches capabilities; `src/components/fresh-agent/FreshAgentSettingsButton.tsx` builds static-only `modelOptions` (L83) for the simple-list radio UI (radio `onChange` list, gate on `modelOptions.length > 0`), fetches capabilities only for freshopencode into `opencodeCapabilities` (L79/L137-144), identifies the claude family via `paneContent.provider === 'claude'` (L89 `keepsSimpleModelList`), and renders statics instantly (no loading state exists; the opencode list simply swaps rows when the probe resolves — LB-7).
